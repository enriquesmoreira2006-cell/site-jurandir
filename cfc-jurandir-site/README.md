# CFC Jurandir — Site

Site institucional responsivo criado com HTML, CSS e JavaScript.

## Arquivos
- `index.html` — estrutura e conteúdo
- `style.css` — visual responsivo em branco, amarelo e preto
- `script.js` — menu mobile e ano automático

## Personalização
1. Abra `index.html` para alterar textos, links e informações.
2. Para colocar fotos reais, substitua os blocos da seção "Galeria" por imagens.
3. O WhatsApp está configurado para `(31) 3852-2555`.
4. Endereço usado: Av. Getúlio Vargas, 5488 — Carneirinhos, João Monlevade — MG.

## Publicar no GitHub Pages
Envie os três arquivos para um repositório público e, em:
Settings → Pages → Build and deployment,
selecione `Deploy from a branch`, escolha `main` e `/ (root)`.
